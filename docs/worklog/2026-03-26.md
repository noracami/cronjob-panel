## 技術討論筆記

### OAuth2 vs SSO
- **OAuth2**：授權協議，讓第三方應用取得使用者在某平台上的資料。各專案 session 獨立。
- **SSO**：一次登入，多個系統共享登入狀態（例如同組織不同 domain 的服務）。
- Discord OAuth 拿到的 `discord_id` 是全域的，不管透過哪個 Discord App 授權，同一使用者的 ID 都一樣。
- 多個專案可共用一個 Discord App（同一組 Client ID / Secret），差別只在管理面（授權畫面名稱、Secret 洩漏影響範圍）。

### SQLite 適用性
- 這個專案的使用情境適合 SQLite：資料量小、單 process 存取、WAL 模式防斷電損壞。
- 部署時需掛 persistent volume，否則容器重啟會遺失資料。
